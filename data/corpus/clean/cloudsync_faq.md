# Acme CloudSync: Frequently Asked Questions

## What is the maximum file size?

A single file can be up to 50 GB.

## Are files encrypted?

Yes. Files are encrypted in transit with TLS 1.3 and at rest with AES-256.

## Can deleted files be recovered?

Deleted files stay in the trash for 30 days on all plans, and can be restored by the user or an admin.

## Where is customer data stored?

All customer data is stored in data centres in the European Union.
